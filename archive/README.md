# Archived skills

Archives preserve historical packages and experiments; they are not discoverable or installable from registry/. Their old routing, effects, commands, and replacement names are historical, not current guidance.

The current architecture is in ../README.md. See ../docs/registry-rebuild.md for the disposition of main's 24 packages and the earlier rebuild. registry-rebuild/ contains the fourteen newly retired entry points at their latest main contents, the initial migration record, old routing cases, and extraction scripts. Earlier family archives remain intact.

Do not restore an archived package merely to satisfy an old route. Establish a current user need, a distinct responsibility, and behavioral evidence first. Extract only useful guidance or tools with a maintained owner.
