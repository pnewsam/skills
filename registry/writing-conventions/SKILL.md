# Writing conventions

Shared kernel for how the text these skills produce should *read*. It covers the sentence-level style of every concise, human-facing technical artifact — PR titles, bodies, and code reviews; Linear issues and projects; planning and charter documents; commit messages — so one voice carries across all of them however each is produced.

Scope: this governs prose *style*, not artifact *structure*. What each artifact must contain — its headings, required sections, checklists — lives in that skill's own standard: the PR content standard for pull requests, the issue and project templates for Linear, the charter and plan shapes for planning docs. Where a repository template exists, its structure wins; these rules only shape the prose that fills it.

Read `references/prose.md`.
